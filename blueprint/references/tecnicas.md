# Técnicas de ideação

> Consulte este arquivo quando o tema pedir mais profundidade do que uma simples lista de ideias — use uma ou combine técnicas conforme o contexto, sem aplicar todas de uma vez.

## SCAMPER

Gere variações de uma ideia existente perguntando: o que **S**ubstituir, **C**ombinar, **A**daptar, **M**odificar (ou ampliar/reduzir), **P**ropor para outro uso, **E**liminar, ou **R**everter/rearranjar. Útil quando já existe um produto/ideia de partida e o objetivo é explorar variações dele.

## Como Poderíamos... (HMW)

Reformule o problema como uma pergunta aberta começando com "Como poderíamos...". Isso evita fechar prematuramente numa solução única e abre espaço para múltiplas respostas divergentes antes de convergir. Útil no início do processo, quando o objetivo ainda está vago.

## Inversão

Pergunte o oposto do objetivo (“como garantir que o produto falhe?”) para revelar restrições, riscos e suposições ocultas — depois inverta as respostas de volta em ideias. Útil quando as ideias geradas estão repetitivas ou óbvias demais.

## Analogias

Busque como outros domínios ou produtos (fora da área de atuação do usuário) resolvem um problema parecido, e adapte o mecanismo para o contexto atual. Útil para destravar quando o usuário está preso em soluções convencionais do próprio setor.
